# Brief coverage

Every requirement of `docs/BRIEF.md`, one row per checkable claim, with its status and its evidence. `tools/coverage.test.ts` holds this page to the repository:

- every row of the roadmap's Brief coverage table appears here, word for word, in the first column (a `″` repeats the row above for a claim split in two);
- a **met** row has evidence, and every evidence path exists; a `path::title` names a test whose title is in that file;
- **met, owner check remains** says the owner's check is on a Playtest issue (feel, real hardware and real networks are the owner's call, `CLAUDE.md`), and still names what is checked automatically;
- **after 1.0** is only what the brief itself puts after 1.0: mobile.

The milestones that deliver each row stay in the roadmap's table; this page says how each is shown.
